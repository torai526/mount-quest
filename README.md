# マウントクエスト 封印の盤上

**駒を倒すな。封印せよ。**

マウントクエストは、大きな駒で小さな駒を封印し、封印された駒の覚醒と逆転を読み合う無料ファンタジー戦略ボードゲームです。

## 無料プレイ

[マウントクエストをブラウザーで遊ぶ](https://torai526.github.io/mount-quest/)

インストール不要です。スマートフォンではホーム画面へ追加すると、アプリのように起動できます。

## 公式トレーラー

「封印」と「覚醒」の独自ルールを約30秒で紹介しています。

[マウントクエスト公式トレーラーをYouTubeで見る](https://youtu.be/-vrzGmB9vMo)

## ゲームの特徴

- 大きな駒で小さな駒を封印する独自ルール
- 上の駒が移動すると、封印された駒が再び覚醒
- 3×3・4×4盤面
- 初級から最強まで選べるAI対戦
- 同じ端末で遊べる2人対戦
- 絶対神による勝利への神託
- 対局の分岐点を振り返る対局解析
- クエスト、冒険者レベル、称号、キャラクター図鑑

## 対応環境

- Google Chrome
- Microsoft Edge
- Safari
- iPhone / iPad
- Android
- Windows / Mac

## セーブデータについて

セーブデータは使用中のブラウザー内に保存されます。ブラウザーのデータを削除すると、セーブデータも削除される場合があります。

端末を変更する場合は、ゲーム内の「セーブ管理」からバックアップを書き出してください。

## プライバシー

マウントクエストは、戦績、設定、クエスト進行、レベル、称号などを利用者のブラウザー内に保存します。

ゲーム独自のサーバーへ、個人情報やセーブデータを送信しません。

本ゲームはGitHub Pagesを利用して配信しています。GitHubのサービスにおけるデータの取り扱いについては、GitHubのプライバシーステートメントをご確認ください。
