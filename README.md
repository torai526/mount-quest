# マウントクエスト 3.0

大きな駒で小さな駒をマウントしながら、縦・横・斜めの完成を目指す思考型ボードゲームです。

## 収録機能

- AI対戦、2人対戦
- 3x3、4x4盤面
- 初級、中級、上級、最強AI
- 最強AIを上回る絶対神の助言
- 対局後の評価グラフ、ベストプレー、分岐点
- 過去局面への復元
- クエスト第1章、星評価
- 冒険者レベル、経験値、連勝、称号
- キャラクター図鑑、熟練度
- デイリークエスト、スタンプ
- 盤面テーマ、スキン
- PWA、オフライン対局
- セーブデータの書き出しと復元

## セーブデータ

戦績や設定は端末内に保存されます。v3.0ではJSON形式でバックアップを作成し、別のブラウザーや端末へ復元できます。

## プライバシー

個人情報や対局記録を外部サーバーへ送信しません。
