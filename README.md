# マウントクエスト

大きな駒で小さな駒をマウントしながら、
縦・横・斜めの完成を目指す思考型ボードゲームです。

## プレイ

https://torai526.github.io/mount-quest/

ブラウザーですぐに遊べます。
スマートフォンではホーム画面へ追加すると、
アプリのように起動できます。

## 対応環境

- Google Chrome
- Microsoft Edge
- Safari
- iPhone / iPad
- Android
- Windows / Mac

## セーブデータについて

セーブデータは使用中のブラウザー内に保存されます。
ブラウザーのデータを削除すると、セーブデータも削除される場合があります。

端末を変更する場合は、ゲーム内の「セーブ管理」から
バックアップを書き出してください。
## プライバシー

マウントクエストは、戦績、設定、クエスト進行、
レベル、称号などを利用者のブラウザー内に保存します。

ゲーム独自のサーバーへ、個人情報やセーブデータを送信しません。

本ゲームはGitHub Pagesを利用して配信しています。
GitHubのサービスにおけるデータの取り扱いについては、
GitHubのプライバシーステートメントをご確認ください。

本ゲームのソースコード、画像、音声、名称、
